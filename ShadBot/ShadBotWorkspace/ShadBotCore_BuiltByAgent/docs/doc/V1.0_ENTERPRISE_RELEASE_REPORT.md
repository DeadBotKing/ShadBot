## 3. Final Production Architecture & Governance

### 3.1 Architecture Freeze
- **Clean Architecture Guarantee**: `Presentation -> Application -> Domain <- Infrastructure` dependency direction is strictly enforced.
- **Contract Freeze**: All core contracts (`AgentContract`, `ToolContract`, `MemoryRepository`, `LLMProvider`, `EventListenerContract`, `MessageReceiverContract`) are permanently frozen for V1.x backward compatibility.
- **Stateless Application Services**: All orchestrators and flow services maintain zero implicit global mutable state.

### 3.2 Production SLA & Cross-Platform Support
- **Windows / Linux / macOS Guarantee**: All filesystem operations use `pathlib.Path`; all string/markdown parsers are line-ending invariant (`.splitlines()`).
- **Offline / Sandbox Resilience**: Pre-commit and test execution environments gracefully handle offline LLM endpoints (`OllamaProvider` socket checks) and pytest recursion prevention (`PYTEST_CURRENT_TEST`).
