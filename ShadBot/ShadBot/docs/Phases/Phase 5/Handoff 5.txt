# Phase 5 — Brain Orchestrator

# Complete Handoff Document

## Mission

ساخت کامل Brain اصلی ShadBot Agent Platform.

این فاز مسئول «مغز» سیستم است.

Brain باید بتواند:

* Task پروژه را دریافت کند
* هدف را بفهمد
* وضعیت پروژه را ببیند
* اطلاعات لازم را جمع کند
* از Memory استفاده کند
* Reasoning انجام دهد
* تصمیم بگیرد
* برنامه ساخت ایجاد کند
* Agent مناسب را انتخاب کند
* اجرای کار را مدیریت کند
* نتیجه را بررسی کند
* از تجربه یاد بگیرد

بعد از این فاز، سیستم باید بتواند:

فقط با دریافت:

```
Project Workspace
    |
    └── Tasks
          |
          └── task.md
```

کار را شروع کند و تا پایان مدیریت کند.

# 5.14 Task Intake Layer

## Purpose

ورودی اصلی Brain.

Task باید از Workspace همان پروژه خوانده شود.

Example:

```
Project Workspace

Meryx

├── Tasks

│     └── task.md
```

Brain نباید Task را از جای دیگری بخواند.

---

## Project Workspace Task Discovery

وظیفه:

پیدا کردن Workspace پروژه.

Input:

```
Project Path
```

Output:

```
Workspace Context
```

---

## Task Input Interface

ایجاد Interface استاندارد:

Example:

```python
TaskInputProvider
```

مسئول:

* دریافت Task
* ارسال به Brain

---

## Task File Reader

خواندن:

```
Tasks/task.md
```

Extract:

* Title
* Description
* Requirements
* Constraints
* Completion Criteria

---

## Task Parser

تبدیل Markdown به مدل داخلی.

Example:

Input:

```md
Build Trading Platform

Requirements:
- MT5
- AI Model
```

Output:

```
TaskEntity
{
 goal,
 requirements,
 constraints
}
```

---

## Task Normalizer

تبدیل Task خام به فرمت قابل فهم Brain.

مثلاً:

Raw:

"یه ربات ترید بساز"

Normalized:

```
Goal:
Create Trading System

Requirements:
Trading
AI
Backtesting
```

---

## Task State Manager

مدیریت وضعیت:

States:

```
CREATED

↓

ANALYZING

↓

PLANNING

↓

EXECUTING

↓

VALIDATING

↓

COMPLETED
```

---

## Task Completion Reporter

خروجی نهایی:

Example:

```
Task Completed

Project:
ShadBot Trader

Status:
SUCCESS

Validation:
PASSED
```
