\# ShadBot Project Intelligence - Handoff Document



\## Project



Name:

ShadBot



Module:

Project Intelligence Engine



Current Architecture Version:

Foundation Phase



Purpose:



Project Intelligence is the understanding layer of the Autonomous Software Engineer platform.



Responsibilities:



\- Scan software projects

\- Understand structure

\- Build project snapshots

\- Analyze technology stack

\- Build project knowledge

\- Provide context for AI agents



Non Responsibilities:



\- Generate source code

\- Modify projects directly

\- Execute development tasks



Those responsibilities belong to Agent Platform.
